# Saia's Super Meat Market

Mandeville, Louisiana meat market site for [Saia's](https://www.facebook.com/SaiasMeatMarket) at 2225 Florida Street.

Butcher counter, famous fried chicken, po-boys, homemade chicken salad, and wine since 1977.

## Stack

TanStack Start, React, Tailwind.

```bash
npm install
npm run dev
```

Runs on `http://localhost:8080`.
